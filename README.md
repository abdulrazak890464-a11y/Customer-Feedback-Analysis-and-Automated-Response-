# Customer Feedback Analysis and Automated Response

## Project Overview

This project analyzes customer reviews using **Python and Pandas**, identifies critical negative feedback using a **rule-based approach**, extracts common complaint keywords, and uses **Generative AI (Google Gemini)** to generate personalized and empathetic customer-support emails.

## Objectives

- Load and clean a customer review dataset.
- Handle missing values and duplicate records.
- Clean customer feedback text.
- Identify critical reviews using a rating-based rule.
- Find common complaint keywords using Python string processing and `Counter`.
- Select three detailed negative reviews with different complaint types.
- Use Google Gemini to generate personalized apology emails.
- Present the analysis and generated responses in a Jupyter Notebook.

## Dataset

The project uses a Flipkart customer review dataset.

### Dataset Columns

|---|---|
| `Product_name` | Name of the reviewed product |

## Data Cleaning

The following operations were performed:

- Converted the `Rate` column into numeric values.
- Removed rows without a valid rating.
- Removed duplicate records.
- Filled missing `Review` and `Summary` values.
- Combined `Review` and `Summary` into a `Feedback` column.
- Converted text to lowercase.
- Removed special characters.
- Removed extra spaces.

Example:

```python
def clean_text(text):
    text = str(text).lower()
    text = re.sub(r'[^a-zA-Z0-9\s]', '', text)
    text = re.sub(r'\s+', ' ', text).strip()
    return text
```

## Rule-Based Critical Review Filtering

No machine-learning model was used for the initial filtering.

Reviews with a rating of **1 or 2 stars** were classified as critical reviews.

```python
critical_reviews = df[df["Rate"] <= 2].copy()
```

## Complaint Keyword Analysis

Complaint-related keywords were searched within critical reviews using Python's `Counter`.

Important keywords included:

- bad
- quality
- waste
- worst
- poor
- disappointed
- problem
- issue
- damaged
- broken
- defective
- refund
- wrong
- missing

The most frequent complaint keywords included **bad, quality, waste, worst, poor, and disappointed**.

## Generative AI Integration

Google Gemini was used to generate personalized customer-support emails.

Install the SDK:

```python
pip install -U google-genai
```

Initialize the client:

```python
from google import genai

client = genai.Client()
```

The project used:

```text
gemini-3.5-flash-lite
```

The prompt instructs Gemini to:

- Address the customer's specific problem.
- Acknowledge the customer's frustration.
- Apologize sincerely.
- Keep the email professional and concise.
- Avoid inventing refunds, compensation, or promises.
- Include a suitable subject line.
- Not mention that the response was generated by AI.
